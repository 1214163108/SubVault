S

SubVault

一个只在本机运行的 Chromium 密码管理器。

数据与隐私

  • 密码库使用 PBKDF2-HMAC-SHA512（310,000 次迭代、32 字节随机盐）派生密钥，再用 AES-256-GCM 加密后写入 chrome.storage.local。
  • 解锁后仅把派生密钥保存在 chrome.storage.session 内存中，浏览器关闭或自动锁定即清除。
  • 备份可以选择独立备份密码：用新的随机盐重新加密，不再依赖主密码。
  • 没有云端、没有账号、没有统计和远程请求；所有数据只存在当前浏览器配置中。
  • 加密备份可以复制到其他设备，但需要备份文件创建时的主密码才能解密。

权限说明

  • storage：保存加密密码库和设置。
  • alarms：每分钟检查是否到达自动锁定时间。
  • idle：系统锁屏或空闲时自动锁定。
  • activeTab：读取当前标签页域名，用于匹配账号。
  • privacy：仅在你手动开启时，关闭 Chrome 自带的“保存密码”提示。
  • clipboardRead（可选）：仅在设置页手动授权后，用于确认剪贴板仍是刚复制的密码再自动清空。
  • 网页访问权限：在 http/https 登录框中提供填充入口；不读取页面其他内容。

已知边界

  • Chrome 不允许扩展移除输入框内的原生钥匙图标，也无法通过扩展 API 完全停用密码管理器；只能尽量抑制自动填充并接管交互。
  • 浏览器导出的 Chrome/Edge CSV 不含时间列，SubVault 会使用文件修改时间作为记录时间。
  • 主密码无法找回；忘记后只能重置密码库。
  • CSV 导出是明文，请在设置页二次验证主密码后妥善处理。
  • 所有账号数据都通过 DOM 文本节点写入页面，不使用 innerHTML 拼接用户数据。
  • 扩展没有任意文件系统路径：数据在扩展存储中，导出文件由浏览器下载目录管理。
